# Frontend — Visión General

## Stack Frontend

| Tecnología | Versión | Uso |
|---|---|---|
| Tailwind CSS | v4.2 | Utilidades de estilos |
| Swiper.js | v12 | Carruseles y sliders |
| Animate.css | v4.1 | Animaciones de entrada |
| Leaflet.js | CDN | Mapas y geolocalización |
| Vanilla JS | ES6+ | Interactividad sin frameworks |

---

## Estructura de Assets

```
public/
├── css/
│   ├── input.css          # Entrada de Tailwind
│   ├── output.css         # Compilado de Tailwind (NO editar)
│   └── [pagina].css       # Estilos específicos por vista
├── js/
│   └── [pagina].js        # Módulo JS por vista
└── uploads/
    ├── products/           # Imágenes de productos
    ├── avatars/            # Fotos de perfil
    ├── reportes/           # Evidencias de reportes
    └── verificaciones/     # Documentos de verificación
```

### Compilación de Tailwind

```bash
# En la raíz del proyecto
npx @tailwindcss/cli -i public/css/input.css -o public/css/output.css --watch
```

## Patrón de una Vista PHP

Cada vista sigue este patrón:

```php
<?php
session_start();
require_once '../../config/conexion.php';  // $conn disponible

// Guard de sesión (en vistas protegidas)
if (!isset($_SESSION['user'])) {
    header('Location: /src/views/auth/login.php');
    exit;
}

$user = $_SESSION['user'];
?>
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <link rel="stylesheet" href="/public/css/output.css">
    <link rel="stylesheet" href="/public/css/[pagina].css">
</head>
<body>
    <?php require_once '../../components/header.php'; ?>
    
    <!-- Contenido de la vista -->
    
    <script src="/public/js/[pagina].js"></script>
</body>
</html>
```

## Módulos JavaScript

Cada página tiene su propio módulo JS en `public/js/`. Los módulos no usan frameworks ni bundlers; son archivos ES6 cargados directamente.

| Módulo | Responsabilidad |
|---|---|
| `home.js` | Inicializar Swiper del hero; animaciones de categorías |
| `all.js` | Filtros del marketplace; paginación; mapa de productos |
| `crear.js` | Mapa Leaflet para seleccionar ubicación; geocodificación inversa; preview de imágenes |
| `edit.js` | Igual que `crear.js` pero pre-carga datos existentes |
| `chat.js` | Conexión WebSocket; envío/recepción de mensajes; scroll al fondo |
| `detalle.js` | Galería de imágenes; botón de favorito; abrir conversación |
| `favorites.js` | Toggle de favoritos con `fetch()` |
| `dashboard.js` | Stats del usuario |
| `header.js` | Menú móvil; contador de mensajes no leídos |
| `login.js` | Validación de formulario; mostrar/ocultar contraseña |
| `register.js` | Validación en tiempo real |
| `perfil.js` | Preview de foto de perfil |
| `mis_productos.js` | Acciones sobre productos (marcar vendido, eliminar) |
| `promociones.js` | Selección de plan; simulación de pago |
| `seller_profile.js` | Tabs de productos/reseñas del vendedor |
